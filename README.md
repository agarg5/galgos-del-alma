# Galgos del Alma

A browser-based 3D RPG built with Three.js. You play a volunteer in golden-hour
Spain, earning the trust of abandoned galgos (Spanish greyhounds) and talking
with LLM-powered villagers whose dialogue is generated by Claude. See
[SPEC.md](SPEC.md) for the full design.

**Live:** https://galgos-del-alma.vercel.app

## Development

```sh
npm install
npm run dev            # game at http://localhost:5173 (or the port vite picks)
```

NPC dialogue goes through a serverless proxy (`api/chat.js`) so no API key is
needed in the browser. To exercise that path locally, run the dev stand-in in a
second terminal — vite proxies `/api/*` to it (see `vite.config.js`):

```sh
ANTHROPIC_API_KEY=sk-ant-... node dev-api.js
```

Players can alternatively paste their own Anthropic API key on the start
screen; it is kept in `sessionStorage` and sent only to `api.anthropic.com`.

## Deployment

Deployed on Vercel. `api/chat.js` needs the `ANTHROPIC_API_KEY` environment
variable set in the Vercel project. Pushing `main` triggers a deploy.

## Architecture

| File | Responsibility |
|---|---|
| `src/state.js` | shared mutable game state |
| `src/scene.js` | renderer, camera, lights, player-following shadow frustum |
| `src/world.js` | terrain heightmap + procedural buildings/trees/roads |
| `src/player.js` | movement, collision, third-person camera |
| `src/galgos.js` | galgo meshes, trust system, care actions, discovery |
| `src/npcs.js` | NPC definitions, patrol |
| `src/dialogue.js` | dialogue UI, Anthropic SSE streaming, discovery unlocks |
| `src/hud.js` | trust panel, zone indicator, milestones, tutorial hints |
| `src/audio.js` | Web Audio ambience + procedural guitar music (muted by default) |
| `src/voice.js` | NPC text-to-speech + microphone input (Web Speech API, no keys) |
| `src/save.js` | session save/continue (position, camera, cooldowns) |
| `src/input.js` | keyboard/mouse handling |
| `api/chat.js` | Vercel serverless proxy for the Anthropic API |

Game progress (galgo trust, NPC conversation history, discoveries) persists in
`localStorage`.
